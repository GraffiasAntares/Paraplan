# Paraplan

Генератор расписания занятий для института на основе **генетического алгоритма**.

Программа на C++ подбирает расписание, в котором нет накладок у преподавателей, аудиторий и учебных групп, а занятия распределены равномерно и с минимумом «окон».

## Возможности

- Генерация расписания генетическим алгоритмом (селекция, скрещивание, мутация)
- Учёт жёстких ограничений: конфликты преподавателей, аудиторий и групп
- Учёт мягких ограничений: окна, равномерность распределения, вместимость и тип аудитории, желаемая нагрузка преподавателя
- Гибкая настройка параметров и весов функции приспособленности в одном файле
- Просмотр результата в HTML (`Paraplan.html`)

## Структура проекта

```
Paraplan/
├── config.h              # параметры алгоритма, веса, тестовые данные
├── genetic_algorithm.h   # реализация генетического алгоритма
├── lesson.h              # описание занятия
├── schedule.h            # описание расписания (особи)
├── app/                  # исходный код приложения
├── Paraplan.xcodeproj    # проект Xcode
├── Paraplan.html         # страница с расписанием
└── концепт.html          # концепт интерфейса
```

## Как это работает

Каждая особь популяции представляет собой полное расписание. На каждом шаге алгоритм оценивает приспособленность особей, отбирает лучшие, скрещивает их и применяет мутации. Так продолжается, пока не будет достигнуто `MAX_GENERATIONS` поколений.

### Функция приспособленности

Качество расписания определяется штрафами, которые умножаются на веса (`FitnessWeights` в `config.h`):

| Параметр | Вес по умолчанию | Что штрафуется |
|---|---|---|
| `hard_conflict` | 1.0 | Конфликты преподавателя, аудитории или группы |
| `soft_gap` | 0.5 | Окна в расписании |
| `soft_balance` | 0.5 | Неравномерное распределение занятий |
| `capacity_conflict` | 0.2 | Нехватка мест в аудитории |
| `type_conflict` | 1.0 | Неподходящий тип аудитории |
| `teacher_load` | 1.0 | Отклонение от желаемой нагрузки преподавателя |

## Настройка

Все параметры находятся в `config.h`.

**Параметры алгоритма:**

| Параметр | Значение | Описание |
|---|---|---|
| `POPULATION_SIZE` | 10 | Размер популяции |
| `MAX_GENERATIONS` | 2000 | Максимальное число поколений |
| `MUTATION_RATE` | 0.05 | Вероятность мутации |

**Размерность задачи (тестовые данные):**

| Параметр | Значение |
|---|---|
| `NUM_GROUPS` | 3 |
| `NUM_TEACHERS` | 5 |
| `NUM_ROOMS` | 6 |
| `NUM_SUBJECTS` | 5 |
| `SLOTS_PER_DAY` | 6 пар |
| `NUM_DAYS` | 6 (включая субботу) |
| `HOURS_PER_CLASS` | 1.5 ч |

**Входные данные**, которые можно заменить своими:

- `groups`, `group_sizes`: учебные группы и их численность
- `teachers`, `subjects`: преподаватели и предметы
- `teacher_subject_pairs`: какой преподаватель какой предмет может вести
- `teacher_desired_hours`: желаемая нагрузка преподавателей (в часах)
- `rooms`, `room_capacities`, `room_types`: аудитории, их вместимость и тип (лекционная, компьютерная, лабораторная)
